# Repository Review 0.1.0 交付范围

独立工程为 Muse-Repository-Review；Muse-Plugin-Ecosystem/plugins/repository-review 仅保留分发入口。原 repository-review 项目的选型记录保留，新工程通过 repository-review-plugin 项目跟踪，避免修改既有归档根。

## 产品与交互

1. 来源：只列操作方授权仓库；选择工作区、暂存区、分支、提交或已配置 GitHub MR。分支、提交解析到不可变 SHA；MR 前后读取 head/base，变化则拒绝该快照。仓库读取不执行 checkout、commit、push、批准或合并。
2. 变更：文件列表显示路径、增删改/重命名状态与已阅；主区展示统一或并排 Diff、原/新全文；保留原始行号、上下文、行内变化、语法颜色。手机提供单列文件选择器和可折行 Diff；长文件每 500 行分段，分页不会丢失其余行。
3. 审阅：点击有来源锚点的行号添加意见，解决/重开意见、标记/撤回已阅、需要修改/完成审阅；摘要绑定、命令去重、进程重启恢复。完整通过要求文件全部已阅、意见已解决且来源没有缺失。回执含比较摘要、来源、意见、委托操作者；明确不属于代码平台批准或合并。
4. 文件版本：通过 Host 公开能力选择明确授权的文件、保存版本、查看完整版本、比较两版本或当前文件、恢复历史。恢复前校验当前摘要并自动备份；若有原生编辑器打开，要求先关闭，避免未保存缓冲覆盖恢复结果。A→B→A 保留三次事件，仅存两份内容 blob。
5. 文件类型：UTF-8 代码、Markdown、TXT、JSON 等完整文本读取与 Diff；PNG/JPEG/WebP 的非文本字节可展示图片及摘要，其他二进制展示字节摘要和十六进制预览。二进制不生成伪文本 Diff；Host 恢复完整字节。首版不宣称所有 Office/PDF/SmartDoc 格式都具有语义级版本合并。
6. 权限：Host 负责文件授权、原生刷新与版本库，插件负责 Git/MR 只读来源、审阅与 UI。Mobile 不接收后端 token，经国内公网中转调用在线 Desktop 的同一安装实例。文件授权是安装方显式给予的 relative path 集合，页面只传 opaque ID。

## 验收门禁

- 独立 MCP 客户端实际发现工具和资源、真实临时 Git 仓库的工作区/暂存/分支/提交、真实授权 MR。
- 2001 行相同文件不被整文件替换；Unicode、无尾换行、空文件、源代码 HTML、非法锚点与超预算均覆盖。
- Desktop 与当前连接 Android PKM110：真实安装入口、代码高亮 Diff、非代码全文、审阅状态、历史比较、恢复备份、重开持久记录。真机报告记录实际服务路径，USB 仅镜像/安装，不转发业务。
- 生产市场上架与代码平台 MR 合并不在本次自动执行范围；未验收项不得写通过。
