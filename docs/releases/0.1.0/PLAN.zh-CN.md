# 0.1.0 实施计划

1. CAP-01：盘点 Host 原生文件版本/Diff、公开 MCP、已安装版本插件与 DSH 参考实现；形成能力矩阵与最小适配边界。
2. VIEW-01：独立审阅数据合同与 UI。优先语法高亮、增删改行、统一/并排与移动可读性；渲染不执行代码。
3. REVIEW-01：复用已发现 Provider 的仓库/版本/MR 读取、引用固定与授权；CI 作为一个调用方，接入同一审阅视图。未发现的能力不得写成已实现。
4. ACCEPT-01：独立 MCP 客户端合同测试、差异边界样本、构建及摘要；真实 Desktop/Find N6 国内公网验收，原生 SmartDoc 用例、报告和 MR 归档。

每项作为独立需求，挂到 Repository Review 0.1.0 交付版本。版本与需求的根节点遵循 Muse-CI 0.6 项目约定。未完成能力、上架和平台合并分别保留状态。
