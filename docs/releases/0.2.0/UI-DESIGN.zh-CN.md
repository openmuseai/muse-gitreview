# 紧凑 Git Tree 与原生 Diff 工作台

采用用户提供的 IDE Git tree 参考：文件列表与内容分栏、目录层级和折叠箭头、单行文件名、状态尾标。内容区保留路径、增删数量和一行工具栏；取消大标题和重复目录字幕，代码为视觉主体。

复用现有 tast 的 product-performs 方向与 look-and-fix 流程；它原本面向展示网站，本任务按用户明确的应用工作台要求保留必要分隔、树结构和工具栏，不引入营销页构图。

原生亮暗主题跟随 OpenMuse。Desktop 目录/文件行30px，触摸44px，代码13px、行高约24px。内容区宽度至少600逻辑像素时固定228px文件树，窄屏通过文件树按钮打开抽屉；实际 PLP110 内屏约691逻辑像素，因此不使用700px阈值。

统一对比显示正负号、行号、语法颜色和背景；并排模式共用垂直行，保留左右行号。未变更区显示“展开 N 行未变更内容”，点击后原位显示相同内容并提供折叠入口。原/新全文、点击 Diff 行定位、跳转行和当前快照文本查找共享 Open File Viewer 代码组件。语义 LS 与历史快照文本查找的名称、版本范围分别明确。
