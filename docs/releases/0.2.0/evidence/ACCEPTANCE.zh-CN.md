# Repository Review 0.2.0 验收记录

状态：实现与自动检查通过；设备验收尚未全部完成。未标记正式发布或市场上架。

## 交付内容

- 独立工程 Muse-Repository-Review；Ecosystem 的 plugins/repository-review 只保留分发包装。
- 紧凑 Git 文件树、目录折叠、状态与文件名一行展示；Desktop 30px / 触控 44px。
- 插件发布固定摘要的被动 .omreview MCP 资源，由现有 Open File Viewer 打开。
- 原生 Tree-sitter 高亮、统一/并排增删改、原始行号、原/新完整文本、展开折叠未变更内容、Diff 行到全文、行号定位和快照文本搜索。
- 原生文档只读；已阅、意见与审阅管理继续由独立插件及其公开工具执行。历史快照只提供版本固定的文本导航，未冒充当前工作区的语言服务器语义跳转。

## 自动验证

插件 TypeScript 检查、15 项 Node 测试通过；Open File Viewer 14 项测试通过，含新增树折叠、输入校验、全文和上下文展开折叠检查。

Muse-CI 真实执行 27 个节点：版本定义 3 个、四个子需求各 6 个。文档节点的执行来源为 smartdoc-publish，工程检查来源为 project.check；不把它们描述成 AI 自动编程。详见 ci-final-execution.json，其记录每次输入、源码摘要与产物。

MCP 客户端已验证资源声明、读取、SHA 一致、无状态服务实例重建及进程重启后资源恢复；篡改资源拒绝加载。
